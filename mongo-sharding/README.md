# pymongo-api

## Как запустить

1. Запускаем mongodb и приложение

```shell
docker compose up -d
```

2. Заполняем mongodb данными

```shell
./scripts/mongo-init.sh
```

Этот скрипт содержит команды для инициализации конфигурационного сервера, шардов и роутера, а также заполнения базы данных тестовыми данными

## Как проверить

3. Проверка количества документов в каждом из шардов:

```shell
./scripts/check-shards.sh
```

### Если вы запускаете проект на локальной машине

4. Откройте в браузере http://localhost:8080

## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8080/docs
