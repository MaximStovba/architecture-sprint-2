# pymongo-api

## Как запустить

1. Запускаем mongodb и приложение

```shell
docker compose up -d
```

2. Заполняем mongodb данными и первичная настройка

Этот скрипт содержит команды для инициализации конфигурационного сервера, реплик шардов и роутера, а также заполнения базы данных тестовыми данными

```shell
./scripts/mongo-init.sh
```

## Как проверить

3. Проверка количества документов в каждом из реплицированных шардов:

```shell
./scripts/check-shards-replica.sh
```

### Если вы запускаете проект на локальной машине

4. Откройте в браузере http://localhost:8080
