# pymongo-api

## Запуск проекта

### Шаг 1. Переход в директорию

Перейдите в директорию **sharding-repl-cache**:

```shell
cd sharding-repl-cache
```

### Шаг 2. Запуск MongoDB и приложения

```shell
docker compose up -d
```

### Шаг 3. Первичная настройка и заполнение MongoDB данными

Запустите скрипт для инициализации конфигурационного сервера, реплик шардов и роутера, а также заполнения базы тестовыми данными:

```shell
./scripts/mongo-init.sh
```

## Проверка

### Шаг 1. Проверка количества документов в шардах

Запустите скрипт для проверки распределения документов по реплицированным шардам:

```shell
./scripts/check-shards-replica.sh
```

### Шаг 2. Если запуск на локальной машине

Откройте в браузере http://localhost:8080

## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8080/docs
